# 🤖 AI Productivity Assistant

An intelligent task management web application that helps users organize their daily tasks, track productivity, and receive AI-inspired recommendations based on task completion patterns. The application provides real-time productivity insights through interactive charts and a clean, responsive dashboard.

Live Link : https://ankush126863.github.io/AI-Productivity-Assistant/

## ✨ Features

- ✅ Add, complete, and delete tasks
- 🎯 Set task priority (Low, Medium, High)
- ⏱️ Assign estimated completion time for each task
- 📊 Real-time Productivity Score
- 📈 Weekly Productivity Trend visualization
- 🥧 Time Allocation Analytics using Pie Chart
- 🤖 AI-inspired Smart Recommendations
- 🗑️ Clear completed tasks
- 📱 Fully responsive design
- 🎨 Modern UI built with Tailwind CSS

The dashboard displays:

- **Productivity Score**
- **Focus Time**
- **Task Velocity**
- **Task Completion Status**
- **Time Allocation Chart**
- **Weekly Productivity Trend**
- **AI Productivity Suggestions**

---

## 🤖 AI Recommendations

The application analyzes your tasks and provides smart suggestions such as:

- Prioritize important tasks
- Break large tasks into smaller chunks
- Improve task completion rate
- Identify overdue tasks
- Maintain a balanced workload

## 💻 Usage

1. Enter your task.
2. Choose a priority level.
3. Specify the estimated time.
4. Click **Add Task**.
5. Mark tasks as completed.
6. Monitor productivity metrics.
7. View AI-generated recommendations.
